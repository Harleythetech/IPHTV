# IPHTV

A curated, Philippine-focused IPTV playlist compiled from publicly available web streams.

> [!NOTE]
> ### Repository Status: PR-Only Maintenance (October 1, 2026)
> Active daily maintenance of this repository is discontinued.
> 
> * **Stream Updates:** Community-driven. Pull requests to restore broken links, prune inactive streams, or add verified channels will continue to be reviewed and merged.
> * **Dead Links:** Please submit a direct pull request with corrected URLs rather than opening an issue report.
> 
> *Thank you to everyone who has maintained, contributed to, and used this project.*

---

## Playlist URL

Add the following M3U URL directly into your preferred IPTV client (VLC, TiviMate, OTT Navigator, Kodi, etc.):

```text
https://raw.githubusercontent.com/Harleythetech/IPHTV/refs/heads/main/ph.m3u
```

## Contributions

Contributions from the community keep this list functional. If you find an offline stream or have a working stream link to add:

1. Fork this repository.
2. Update the corresponding entry in `ph.m3u`.
3. Submit a pull request detailing the changes made.
